# Formula for Windows (preview)

Version 0.1.83. Download [Formula-Setup.exe](https://github.com/vipinsiders/mergekeeper-releases/raw/windows/Formula-Setup.exe) and run it.
It installs for your Windows account only and does not need an administrator.

This preview is not signed yet, so Windows warns before running it: choose **More info**, then **Run anyway**.

This branch holds only the newest installer and is replaced with every release. The Mac app and its updates are on `main`.
